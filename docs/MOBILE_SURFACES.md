# Mobile surfaces

Generated by `scripts/list-surfaces.py`. Every id here can be switched off from the server's
`config/mobile_ui.php` → `hidden`. A `screen.*` id hides a whole screen (it shows the notice from
`notices`); a `tab.*` id removes a tab; the rest hide one element. Default: everything on.
«assistant: X» = who among a teacher's staff sees it by default (teacher = never an assistant,
else the ability key an assistant must hold); `gates` in `config/mobile_ui.php` overrides that per id.
